# SMS-021 – Level-Streifen-Canvas

| Epic | Meilenstein | Größe | Status |
|---|---|---|---|
| C – Level-Editor | M2 | L | Offen |

## Beschreibung
Der lange Level-Streifen, auf dem gemalt wird.

## Akzeptanzkriterien
- [ ] Darstellung horizontal (breit) bzw. vertikal (hoch) je nach Orientierung
- [ ] Chunk-basiertes Rendering (Offscreen-Canvas-Cache), flüssig bei 64-Screen-Level
- [ ] Zoom (Mausrad) und Pan (Leertaste + Ziehen / mittlere Maustaste)
- [ ] Minimap des gesamten Levels mit klickbarem Sichtfenster
- [ ] Kamerarahmen 256×192 einblendbar, inkl. HUD-Bereich
