# SMS-010 – Paletten-Editor

| Epic | Meilenstein | Größe | Status |
|---|---|---|---|
| B – Grafik-Editoren | M1 | S | Offen |

## Beschreibung
Bearbeitung der zwei 16-Farben-Paletten (Hintergrund, Sprites).

## Akzeptanzkriterien
- [ ] Zwei Paletten à 16 Slots sichtbar, Auswahl per Klick
- [ ] Farbwähler zeigt ausschließlich die 64 Hardware-Farben (8×8-Raster)
- [ ] Sprite-Farbe 0 ist als „transparent“ gekennzeichnet
- [ ] Änderungen wirken sofort in allen Editoren
- [ ] Farben tauschen (Drag) mit optionalem Umschreiben aller betroffenen Pixel
