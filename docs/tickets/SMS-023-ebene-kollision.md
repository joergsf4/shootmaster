## Beschreibung
Separate Ebene für Spiellogik-Attribute des Hintergrunds.

## Akzeptanzkriterien
- [ ] Attribute: leer, fest (blockiert), tödlich, Priorität (BG vor Sprites)
- [ ] Standardwerte kommen aus dem Metatile, pro Zelle überschreibbar
- [ ] Halbtransparentes Overlay mit Farbcodierung, ein-/ausblendbar
- [ ] Ebenen-Umschalter (Grafik / Kollision / Ereignisse)
